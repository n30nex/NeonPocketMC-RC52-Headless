# NeonPocketMC RC52 Headless 1.0 RC1

First experimental screenless BLE companion release for the Heltec RadioCore RC52-L62/SX1262.

- Default pairing PIN: `123456`
- Application-only UF2 at `0x26000`
- Preserves the RC52 bootloader, SoftDevice, MeshCore identity, contacts, channels, and preferences
- No display, framebuffer, Web/AP, USB companion, repeater, or room-server code path
- Built from the current NeonPocketMC RC52 source with the MeshCore RX boosted-gain correction

Use only the assets attached to the matching GitHub release and verify them with `SHA256SUMS.txt` before flashing.
